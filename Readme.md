# 📄 AI PDF Assistant

An AI-powered Retrieval-Augmented Generation (RAG) application that allows users to upload PDFs and ask questions about the document.

## 🚀 Features

- Upload any PDF
- AI-powered question answering
- Semantic search using embeddings
- FAISS vector database
- Streamlit web interface
- Context-aware answers using FLAN-T5

## 🛠 Technologies Used

- Python
- Streamlit
- FAISS
- SentenceTransformers
- HuggingFace Transformers
- FLAN-T5
- PyPDF
